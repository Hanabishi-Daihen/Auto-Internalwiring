# Internal Wiring Planner

โปรแกรมจัดทำ **Internal cable wiring list** ของตู้ควบคุม (TCC / LCC / RCC) จาก Schematic PDF
โดยจัดลำดับการพ่วงสายให้สะดวกต่อการเดินสายจริง ตามตำแหน่งอุปกรณ์ใน **Outline drawing**
แล้วส่งออก Excel ตามฟอร์ม `IN LCC` เดิม

> เปิดใช้งานด้วยการ **ดับเบิลคลิก `index.html`** (Chrome / Edge) — ไม่ต้องติดตั้ง ไม่ต้องใช้ PowerShell ไม่ต้องต่ออินเทอร์เน็ต (ยกเว้นวิธีอ่านแบบ B)
> (ไลบรารีทั้งหมดอยู่ในโฟลเดอร์ `vendor/`)

## ⚡ อัตโนมัติจาก PDF (แท็บแรก)

ใส่แค่ไฟล์ PDF แล้วรัน — โปรแกรมอ่านวงจร หา node สายภายในตู้ วางอุปกรณ์จาก Outline และสร้าง wiring list ให้

1. **📄 เลือกไฟล์** Schematic PDF
2. ใส่ **หน้า Schematic** (เลขหน้า PDF) เช่น `7-22` หรือ `16-38` (ใส่หลายช่วงได้ `7-12,15`)
3. (ถ้ามี) เลือก **ไฟล์ PDF Installing / Outline แยก** — ตัวอักษรใหญ่และชัดกว่าหน้า Outline ที่รวมอยู่ในไฟล์ Schematic
   เมื่อเลือกแล้ว เลขหน้า Outline ในตารางตู้หมายถึงหน้าของไฟล์ Installing (เช่น INSIDE PANEL / FRONT VIEW / SIDE VIEW อยู่หน้า 1–3)
4. ใส่ **ตู้และหน้า Outline** ทีละแถว เช่น `TCC.` → `30` หรือ `LCC.` → `2`, `RCC.` → `3-4`
   (แบบที่มี LCC และ RCC ในหน้าวงจรเดียวกัน โปรแกรมแยกขาให้แต่ละตู้จากกรอบประ `+LCC` / `+RCC`)
5. เลือกวิธีอ่าน แล้วกด **▶ รัน** → ตรวจผลในตาราง (ติ๊ก “เฉพาะรายการที่ควรตรวจ”, ยกเลิกติ๊ก node ที่ไม่ต้องการ)
6. **✔ สร้างโปรเจกต์จากผลนี้** → ตรวจ/แก้ใน Netlist, วางอุปกรณ์ที่เหลือและวาดรางวายเวย์ในแท็บผังอุปกรณ์, ตั้งสี/ขนาดสาย → ส่งออก Excel

## หลักการจัดเส้นทางสาย

1. **ตำแหน่งจริง** — อุปกรณ์แต่ละตัวมีพิกัดจาก Sheet 30 แปลงเป็นมิลลิเมตร (มาตราส่วน ≈ 7.76 mm/pt)
   ขั้ว Terminal คำนวณตำแหน่งตามลำดับขั้วบนราง
2. **รางวายเวย์** — บน mounting plate สายวิ่งตามรางแนวนอน/แนวตั้ง (หาเส้นทางสั้นสุดด้วย Floyd–Warshall)
   อุปกรณ์บน swing panel ออกทาง **ชุดสายบานพับ (HINGE-L / HINGE-R)** และผนังข้างต่อเข้ารางขอบ plate
3. **ลำดับการพ่วง** — ในแต่ละ node เรียงเป็นสายต่อเนื่อง A→B, B→C ที่สั้นที่สุด
   (≤ 11 จุดใช้ DP หาคำตอบที่ดีที่สุด, มากกว่านั้นใช้ greedy + 2-opt + or-opt) ทุกขาอุปกรณ์มีสาย **ไม่เกิน 2 เส้น**
4. **Short link bar** — ขั้วในกลุ่ม bar นับเป็นจุดเดียว และเข้าสายทางขั้วที่ Terminal arrangement แสดงว่าเป็น internal (เช่น P2.21–26, W1, 113)
5. **ช่วงล็อกตามแบบ** — ช่วงที่แบบบังคับผ่าน Terminal (เช่น `TB02:P2.21 → 8FM1:1.12`, `TB03:121 → 8FM1:1.11`) ไม่ถูกเปลี่ยน
6. **ความยาวตัด** = ความยาวเส้นทาง + เผื่อปลายละ 100 mm ปัดขึ้นทีละ 50 mm (ตั้งค่าได้) · สายระหว่างขาบนอุปกรณ์ตัวเดียวกันคิดเป็นจัมเปอร์ 50 mm

## Excel ที่ส่งออก

* **IN TCC** — คอลัมน์ตามฟอร์ม `WIRE MARK 1 | WIRE MARK 2 | LINENO. | CABLE DETAILS | LOC.1 | CMP.1 | PIN.1 | LOC.2 | CMP.2 | PIN.2 | SH.`
  (WIRE MARK เป็นสูตร `CONCATENATE` เหมือนต้นฉบับ) + `LENGTH | CUT | ROUTE | REMARK`
  ช่องสาย/ขนาดว่าง = สีเหลือง, มีหมายเหตุ = สีส้ม, Header/Footer และ print title แถว 1–2, fit to width 1 หน้า
* **SHORT LINK (TB)** — กลุ่ม bar ของแต่ละ TB
* **BUNDLE** — จำนวนและความยาวสายตามกลุ่มเส้นทาง (ใช้เตรียมมัดสาย)
* **CUT LIST** — ความยาวตัดรวมแยกตามสี/ขนาดสาย (ใช้เบิกวัสดุ)
* **NOTES** — ขอบเขต ที่มาของสี/ขนาดสาย จุดในแบบที่ควรตรวจสอบ ข้อจำกัด

## ข้อจำกัดที่ควรรู้

* ตัวอักษรใน Schematic เป็น **เส้น vector ไม่ใช่ข้อความ** — วิธี A อ่านด้วยแม่แบบตัวอักษร (ได้ไม่ครบ 100%)
  netlist ตัวอย่างของ PP1047A ที่มากับโปรแกรมไล่จากภาพแบบทีละ node (`tools/build_pp1047a.py` → `data/pp1047a_tcc.js`) และใช้เป็นเฉลยวัดความแม่น
  ควรตรวจเทียบแบบโดยกรอง Sheet ในแท็บ Netlist / รายการสาย
* หน้า Outline (Sheet 30) มีชื่ออุปกรณ์เป็นข้อความ จึงดึงตำแหน่งจาก PDF ได้โดยตรง
* อุปกรณ์ที่ไม่มีใน Outline (KD1, KD2, BL, 3R, FL1, 92L, Earth bar) ใช้ **ตำแหน่งสมมติ** (กรอบสีส้ม) — ลากไปตำแหน่งจริงได้
* ความยาวสายเป็นค่าประมาณจากมาตราส่วนแบบ

## ใช้กับโปรเจกต์ใหม่ / แบบ Type อื่น (LCC, RCC, LCC+RCC)

ผลศึกษาแบบ 5 Type (PP0817B, PP0985B, PP0915A, PP0922B, PP0993B) ดูที่ [`docs/drawing-study.md`](docs/drawing-study.md)

1. **🆕 โปรเจกต์ใหม่** → ใส่ Process No. และรายชื่อตู้ เช่น `LCC., RCC.`
2. **📄 เปิด PDF** → แท็บผังอุปกรณ์ → **+ หน้า Outline** (ทำทีละตู้ ใส่ LOC. ของหน้านั้น) — ชื่ออุปกรณ์ที่เป็นข้อความในหน้า Outline จะถูกสร้าง/วางให้อัตโนมัติ
3. เลือกเครื่องมือในแท็บผังอุปกรณ์:
   * **▭ วาดมุมมอง** — ลากกรอบ mounting plate / ประตู / ผนังข้าง แล้วกรอกความกว้างจริง (mm) และ LOC.
   * **═ วาดรางวายเวย์** — คลิกจุดเริ่ม–จุดจบบน mounting plate (จับแนวตั้ง/นอน และต่อจุดตัดให้อัตโนมัติ)
   * **⤳ จุดเชื่อม/บานพับ** — คลิกบานพับประตู (หรือปลายรางบนผนังข้าง) แล้วคลิกรางของแผงที่สายวิ่งเข้า
   * **＋ วางอุปกรณ์** / **↔ ย้ายอุปกรณ์** / **✕ ลบ**
4. แท็บ Netlist → เพิ่ม node หรือ **นำเข้า Netlist CSV** (`wire, sheet, class, pins, fixed, keepOrder, remark`)
   * ขาเขียนได้ทั้ง `-K1:13` และ `-X3.201`; ขั้วที่ชื่อซ้ำทุกตู้ใช้ `+RCC-X3.201` / `+LCC-X3.201`
   * node ที่ลากข้ามตู้ (เช่น LCC-X3.201 … RCC-X3.201) ใส่รวมกันได้ โปรแกรมแยกเป็นสายภายในของแต่ละตู้เอง
5. แท็บตั้งค่า → ตั้งตารางสี/ขนาดสายตาม General spec ของงานนั้น (เพิ่ม/ลบประเภทวงจรได้) และ Header/Footer
6. ส่งออก Excel → ได้ชีท `IN LCC`, `IN RCC` … แยกตามตู้

PP1047A ยังสร้างจากสคริปต์ `tools/build_pp1047a.py` (มีลำดับขั้วบน Terminal strip และกลุ่ม short link bar)
