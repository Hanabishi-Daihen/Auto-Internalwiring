1. แบบและช่วงหน้า

ตู้และหน้า Outline

หน้า Outline ใส่ได้หลายหน้า เช่น 3-4 · ถ้าแบบมี LCC และ RCC ในหน้าวงจรเดียวกัน ให้ใส่ทั้งสองตู้ โปรแกรมแยกจากกรอบประ +LCC / +RCC

2. วิธีอ่านแบบ

ภาพแบบจะถูกส่งไปประมวลผลที่ Anthropic — ตรวจนโยบายความลับของบริษัท/ลูกค้าก่อนใช้


      

    

    

      
3. ตรวจทานผล

      

      
    
      
    
        
        
      
    
      
    
      
    
        
        จะแทนที่โปรเจกต์ปัจจุบัน (กด 💾 บันทึกโปรเจกต์ ไว้ก่อนถ้าต้องการ) — แก้ไขต่อได้ในแท็บ Netlist / ผังอุปกรณ์
      
    
    
    
  
    

  
    
    
    
    
    
      
    
        
    ขั้นตอนใช้งาน
    
        
      
          
    1. ตรวจ Netlist — แท็บ Netlist จาก Schematic คือจุดต่อทุก node ที่อ่านจากแบบ Sheet 07–22 แก้ไข/เพิ่มได้ เปิด PDF เทียบได้ในแท็บ ดูแบบ PDF
      2. 
          
    2. ตรวจตำแหน่งอุปกรณ์ — แท็บ ผังอุปกรณ์ แสดงอุปกรณ์บน Outline Sheet 30 ลากย้ายได้ อุปกรณ์ที่ไม่มีใน Outline จะมีกรอบสีส้ม (ตำแหน่งสมมติ)
      3. 
          
    3. จัดเส้นทางสาย — โปรแกรมเรียงลำดับการพ่วงสายในแต่ละ node ให้สั้นที่สุดตามรางวายเวย์ ประตู (hinge) และผนังข้าง โดยแต่ละขาอุปกรณ์มีสายไม่เกิน 2 เส้น
      4. 
          
    4. ส่งออก Excel — ได้ชีท IN TCC ตามฟอร์มเดิม + Short link, Bundle, Cut list, Notes
      5. 
        
    
      
    
      
    
        
    จุดในแบบที่ควรตรวจสอบ
    
        
      
      
      
    
      
    
      
      
      ความยาวสายแยกตามกลุ่มเส้นทาง (Bundle)
